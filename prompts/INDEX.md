- **Writing Documentation** → Use [Documentation](general/documentation.md)
- **Creating Tests** → Use [Testing](general/testing.md)
- **Designing APIs** → Use [API Design](general/api-design.md)
- **Security Analysis** → Use [Security](general/security.md)

### By Programming Language

## Usage Tips

1. **Combine Prompts**: Use multiple prompts for comprehensive assistance
   - Example: Use language-specific prompt + testing prompt for test-driven development
   
2. **Customize**: Adapt prompts to your specific project needs
   
3. **Iterate**: Start with one prompt and refine based on results

4. **Context Matters**: Always provide relevant context when using prompts
